# STM32 Hub 使用教程

## 教程模块结构

当前新手教程采用目录即结构的方式组织内容，根目录位于 `tutorials/`。

已规划的主要层级如下：

- `00-目录`：总览、阅读顺序和章节导航。
- `01-setup-environment`：第一章，环境搭建。
- `02-bluepill-basics`：第二章，小蓝板基础外设实践。
- `03-algorithm-intro`：第三章，常见控制算法入门。
- `04-c-board-and-cat-board`：第四章，控制板、IMU、CAN 与 RTOS。
- `05-whole-robot`：第五章，整车系统联调。

## 内容约定

- 每个章节或分组都放在独立文件夹中。
- 文件夹内存在 `index.md` 时，该节点会在软件中作为可阅读章节出现。
- `meta.json` 用于提供标题、摘要、标签和预计阅读时间。
- 子文件夹会自动作为下级目录递归显示，不需要在中央清单中手工注册。

## 维护方式

1. 新增章节时，优先延续 `NN-slug` 的命名方式，保证排序稳定。
2. 每节都先写清目标、关键概念、实践步骤和常见问题。
3. 打包发布前执行 `npm run dist`，确认 `tutorials/` 与 `docs/` 已进入安装包资源目录。
