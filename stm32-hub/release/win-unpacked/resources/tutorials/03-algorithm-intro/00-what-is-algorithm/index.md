# 第 0 节 · 先分清输入输出：什么叫算法

> 本节目标：把“算法”从抽象名词变成可落地的软件结构。

## 在嵌入式里，算法通常是什么

算法通常就是一段把输入加工成输出的规则。输入可能是传感器、目标值、误差或历史状态；输出可能是电机电流、PWM 占空比、速度指令或估计结果。

## 一个算法最少要说清什么

- 输入来自哪里。
- 中间保存了哪些状态。
- 输出交给谁使用。
- 运行频率是多少。

## 为什么很多人学算法会卡住

因为一开始只盯公式，没有先建立“这段代码到底在解决什么问题”的问题意识。公式只是表达方式，不是全部。

## 一个简单判断标准

如果你能用一句话说出“它把什么变成什么”，那你就已经开始真正理解这个算法了。
