# 第 5 节 · 先定义代价再求最优：LQR 线性二次规划器

> 本节目标：知道 LQR 想做的是“在误差和控制代价之间找平衡”，以及它为什么常出现在平衡类系统里。

## LQR 的核心思路

先定义一个代价函数：状态偏差太大要罚，控制输出太猛也要罚。然后求一组反馈增益，让总成本尽量小。

## 它适合什么场景

- 倒立摆和平衡车
- 线性化后可建模的姿态系统
- 需要兼顾响应速度和控制平滑度的系统

## 学习时别急着背矩阵

你真正要先理解的是：

- 哪些状态最重要。
- 哪些控制动作成本更高。
- 为什么“快”不一定等于“好”。

## 工程提醒

LQR 往往建立在模型足够准确的前提下。模型不准，反馈就会偏。它通常和状态观测器、姿态估计一起出现，而不是单独存在。
