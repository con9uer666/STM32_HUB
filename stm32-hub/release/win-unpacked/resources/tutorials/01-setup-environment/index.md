# 第一章 · 入门：搭建环境

> 本章目标：把 STM32 开发常用的软件链路、生成代码方式和编译下载流程一次理顺，后面做实验时就不会被环境卡住。

## 这一章解决什么问题

- 你应该安装哪些工具，以及它们各自负责什么。
- 用 CubeMX 配置芯片时，哪些设置是后面所有工程都会重复用到的。
- 为什么有人坚持用 Keil，也为什么越来越多人切到 CMake + VS Code。

## 推荐学习方式

1. 先通读本章，建立整体地图。
2. 选择一条主线工具链作为你的日常环境。
3. 跟着第二章做实操时，再回来看对应工具的细节。

## 本章内容

- 第 0 节：认识常见开发环境和推荐组合。
- 第 1 节：学会用 CubeMX 做引脚、时钟和代码生成。
- 第 2 节：掌握 Keil 的导入、编译、下载与调试。
- 第 3 节：搭一套更现代的 CMake + VS Code 工作流。

## 过关标准

学完本章后，你至少应该做到下面四件事：

- 能创建一个新的 STM32 工程。
- 能打开并重新生成初始化代码。
- 能完成一次编译。
- 能把程序下载到板子并看到运行结果。
