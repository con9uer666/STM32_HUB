# 第 0 节 · 与嵌入式接轨：主流环境介绍

> 本节目标：先把工具之间的分工搞明白，避免一上来就同时被芯片、工程结构和 IDE 配置绊住。

## 一条完整开发链路包含什么

做 STM32 开发，通常会经过这几个环节：

1. 选芯片、配时钟、配引脚。
2. 生成底层初始化代码。
3. 编写应用逻辑。
4. 编译、链接，产出固件。
5. 下载到板子上并调试。

不同工具的区别，本质上是在上面这些环节里各自负责哪一段。

## 常见工具怎么分工

| 工具 | 主要作用 | 适合谁 |
| --- | --- | --- |
| STM32CubeMX | 配置芯片资源并生成初始化代码 | 所有人 |
| Keil MDK | 传统一体化 IDE，编译、下载、调试一站式完成 | 想先快速跑起来的初学者 |
| ARM GCC + CMake + VS Code | 更灵活的工程管理和现代编辑体验 | 想拥有现代开发体验的人 |
| ST-Link / DAP-Link | 下载和调试程序 | 所有人 |

## TARS Go电控主要使用的工具链

- CubeMX生成初始化代码和基本外设库
- Keil编辑代码、调试编译

本教程所有内容都基于CubeMX+Keil的工具链进行，提供CMake + VS Code的教程是为了给大家开拓眼界

## 安装前要记住的事

- 路径中不允许出现中文和空格，很多工具对中文路径和空格的支持非常不友好，很容易造成恶性错误。
