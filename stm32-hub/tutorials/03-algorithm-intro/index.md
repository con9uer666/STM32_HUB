# 第三章 · 进阶：初识算法

> 本章目标：把控制项目里最常见的几种算法先建立起直觉，知道它们分别解决什么问题，掌握每种算法的完整实现和调参方法，而不是一上来就陷进公式细节。

## 为什么嵌入式项目绕不开算法

当你开始处理速度、角度、位置、姿态、滤波和控制，代码就不只是”让外设动起来”，而是在做”根据信号做决策”。这就是算法的入口。

第二章你学会了让外设工作——GPIO、定时器、串口、I2C、SPI。但光会操作外设还不够：电机不能一步跳到目标速度（需要斜坡），传感器数据有噪声（需要滤波），系统要跟上目标值（需要 PID），多个传感器数据要融合（需要卡尔曼），复杂系统要最优控制（需要 LQR）。

## 本章怎么读更有效

- **先理解每种算法的用途**，再关心实现。每一节开头都会先讲”它解决什么问题”。
- **先画输入和输出**，再看中间状态。每种算法都可以用”什么进去、什么出来”一句话概括。
- **先跑通代码**，再考虑理论推导。每一节都有完整的 C 代码实现和 STM32 使用示例。
- **动手做任务**。每一节末尾的任务是按难度递进设计的，做完才算真正理解。

## 本章内容

| 节 | 算法 | 解决什么问题 | 难度 |
| --- | --- | --- | --- |
| 第 0 节 | 算法基础概念 | 建立”输入-状态-输出”的思维框架 | 入门 |
| 第 1 节 | 斜坡（Ramp） | 指令跳变导致的机械冲击 | 入门 |
| 第 2 节 | 低通滤波（LPF） | 传感器数据噪声太多 | 入门 |
| 第 3 节 | PID | 让系统快速、精确地跟上目标值 | 核心 |
| 第 4 节 | 卡尔曼滤波 | 多传感器数据融合和状态估计 | 进阶 |
| 第 5 节 | LQR | 多状态耦合系统的最优控制 | 进阶 |

建议按顺序学习。第 0~2 节是基础，第 3 节（PID）是本章核心，第 4~5 节是进阶内容。

## 过关标准

学完本章后，你应该能回答三件事：

- 这个算法的**输入**是什么。
- 它**输出**什么给系统。
- 它在什么场景下比别的算法**更合适**。

并且能在 STM32 上独立实现斜坡、低通滤波和 PID 这三个最常用的算法。
