# 第三章 · 进阶：初识算法

> 本章目标：把控制项目里最常见的几种算法先建立起直觉，知道它们分别解决什么问题，而不是一上来就陷进公式细节。

## 为什么嵌入式项目绕不开算法

当你开始处理速度、角度、位置、姿态、滤波和控制，代码就不只是“让外设动起来”，而是在做“根据信号做决策”。这就是算法的入口。

## 本章怎么读更有效

- 先理解每种算法的用途，再关心实现。
- 先画输入和输出，再看中间状态。
- 先做离散实现，再考虑理论推导。

## 本章内容

- 第 0 节：什么是算法，以及它在嵌入式里通常长什么样。
- 第 1 节到第 2 节：先学最容易上手的斜坡和低通滤波。
- 第 3 节到第 5 节：再进入 PID、卡尔曼和 LQR 这类常见控制算法。

## 过关标准

学完本章后，你应该能回答三件事：

- 这个算法的输入是什么。
- 它输出什么给系统。
- 它在什么场景下比别的算法更合适。
