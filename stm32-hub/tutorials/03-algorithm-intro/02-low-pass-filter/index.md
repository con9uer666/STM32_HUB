# 第 2 节 · 先压掉高频噪声：低通滤波器

> 本节目标：理解为什么传感器数据不能原样直接拿去控制，以及最简单低通滤波的实现方式。

## 它在做什么

低通滤波保留慢变化趋势，压制高频噪声。它不会创造信息，只是在“响应速度”和“平滑程度”之间做权衡。

## 一阶低通常见写法

```c
filtered = filtered + alpha * (raw - filtered);
```

`alpha` 越大，响应越快；越小，输出越平滑。

## 适合什么场景

- ADC 采样平滑
- IMU 原始数据去毛刺
- 速度估计的简单平滑处理

## 注意事项

滤波不是越重越好。滤得太狠，控制系统会变“慢半拍”。
