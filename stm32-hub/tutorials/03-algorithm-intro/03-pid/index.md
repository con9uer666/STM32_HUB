# 第 3 节 · 先用误差闭环：PID

> 本节目标：理解 PID 的三个分量分别在补什么，并知道最基本的调参顺序。

## PID 在控制什么

PID 用目标值和当前值之间的误差，算出一个控制输出，让系统尽快、平稳地靠近目标。

## 三个分量的直觉

- P：误差有多大，就给多大力度。
- I：长期有偏差，就慢慢补回来。
- D：变化太快时，先踩一脚刹车。

## 调参顺序建议

1. 先只开 P。
2. P 能基本跟上后，再少量加 I 消除静差。
3. 系统容易抖或超调时，再考虑 D。

## 经验提醒

PID 不万能。执行器饱和、采样噪声、模型延迟都可能让它表现很差，所以实现时通常还要配合限幅、积分分离、输出滤波等保护。
