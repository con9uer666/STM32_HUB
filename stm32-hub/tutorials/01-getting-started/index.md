# 第 1 章 · 入门：搭好开发环境

> 本章目标：理解 STM32 是什么，准备好后续章节需要的全部软件工具。

## 1.1 STM32 是什么？

STM32 是意法半导体（ST）推出的基于 ARM Cortex-M 内核的 32 位微控制器系列。
它常用于：

- 物联网 / 智能硬件
- 电机控制
- 工业仪表
- 学生竞赛（电赛、智能车、机器人）

> **小贴士**：本教程默认以 **STM32F103C8T6**（俗称 BluePill）为例讲解，因为它便宜、资料多、外设齐全。

## 1.3 推荐学习路线

1. 从「点灯」开始 → GPIO
2. 串口收发 → USART
3. 定时器中断 → TIM
4. ADC 采样 → 模拟输入
5. PWM 输出 → 调光、电机
6. 通信协议 → I²C / SPI

> 后面每一章都会给出一个**最小可运行**的工程示例，配合本软件的「新建工程 → 模板 .ioc」一键生成。
