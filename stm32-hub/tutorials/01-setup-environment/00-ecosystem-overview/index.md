# 第 0 节 · 与嵌入式接轨：主流环境介绍

> 本节目标：先把工具之间的分工搞明白，避免一上来就同时被芯片、工程结构和 IDE 配置绊住。

## 一条完整开发链路包含什么

做 STM32 开发，通常会经过这几个环节：

1. 选芯片、配时钟、配引脚。
2. 生成底层初始化代码。
3. 编写应用逻辑。
4. 编译、链接，产出固件。
5. 下载到板子上并调试。

不同工具的区别，本质上是在上面这些环节里各自负责哪一段。

## 常见工具怎么分工

| 工具 | 主要作用 | 适合谁 |
| --- | --- | --- |
| STM32CubeMX | 配置芯片资源并生成初始化代码 | 所有人 |
| Keil MDK | 传统一体化 IDE，编译、下载、调试一站式完成 | 想先快速跑起来的初学者 |
| ARM GCC + CMake + VS Code | 更灵活的工程管理和现代编辑体验 | 想做长期项目或多人协作的人 |
| ST-Link / J-Link | 下载和调试程序 | 所有人 |

## 新手怎么选更稳

如果你是第一次接触 STM32，建议这样选：

- 想尽快点亮 LED：CubeMX + Keil。
- 想以后做更大工程：CubeMX + CMake + VS Code。
- 不确定自己适合哪条路：先用 Keil 跑通，再切到 CMake，不冲突。

## 推荐安装顺序

1. 驱动和下载器工具。
2. CubeMX。
3. Keil 或 ARM GCC 工具链。
4. VS Code 及扩展。
5. 本软件 STM32 Hub。

这样做的好处是，前一个环节有问题时，问题范围很小，排查成本低。

## 安装前先记住三件事

- 路径尽量避免中文和空格，很多老工具对路径仍然敏感。
- 默认使用 3.3V 逻辑电平，不要拿 5V 串口模块直接硬怼板子。
- 每装完一个关键工具，都做一次最小验证，不要等全部装完再一起排错。

## 这一节学完后你该做什么

选定你准备使用的主线工具链，然后继续看 CubeMX。无论你最后用 Keil 还是 CMake，CubeMX 都是 STM32 初学阶段最常见的入口。
