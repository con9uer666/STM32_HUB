# 第 0 节 · 没摸过就不算上手：认识小蓝板（STM32F103C8T6）

> 本节目标：先认识你接下来会一直打交道的这块板子，知道它能做什么、怎么供电、怎么下载、哪些引脚最常用。

## 小蓝板为什么常被拿来入门

STM32F103C8T6 这颗芯片资源适中，价格低，社区资料丰富，拿它练习基础外设非常合适。

它的常见特征包括：

- Cortex-M3 内核，主频常见为 72MHz。
- 常用外设齐全：GPIO、定时器、USART、I2C、SPI、ADC 等。
- 板载 8MHz 晶振、3.3V 供电和一颗板载 LED。

## 先记住这些硬件常识

### 板载 LED

很多小蓝板把 LED 接在 PC13，并且是低电平点亮。也就是说，输出 0 才亮，输出 1 才灭。

### 下载接口

最常见的是 SWD：

- SWDIO
- SWCLK
- 3.3V
- GND

连接 ST-Link 时，先确认供电和地线，再看信号线。

### 串口电平

板子是 3.3V 逻辑，接 USB 转串口模块时也要确认对方是 3.3V，不要默认都能混用。

## 初学时最值得关注的引脚

| 引脚 | 常见用途 |
| --- | --- |
| PC13 | 板载 LED |
| PA9 / PA10 | USART1 TX / RX |
| PA6 / PA7 | 常见 PWM / SPI 复用 |
| PB6 / PB7 | 常见 I2C1 复用 |
| PA13 / PA14 | SWD 调试接口 |

## 上电和接线的基本原则

- 共地永远优先。
- 先断电接线，后上电测试。
- 下载器、串口模块、传感器同时接入时，先保证供电来源清晰，不要多路硬顶。

## 本节建议动作

拿出你的板子，对照资料把 LED、串口、SWD、5V/3.3V/GND 位置都认一遍。后面真正调试时，越熟悉物理板子，排错越快。
