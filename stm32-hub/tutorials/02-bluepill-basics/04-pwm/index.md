# 第 4 节 · 用占空比控制能量：PWM

> 本节目标：理解 PWM 的频率和占空比，并让一个引脚输出可调占空比波形。

## PWM 到底是什么

PWM 是脉冲宽度调制。它通常保持固定周期，只改变高电平持续时间的占比。

占空比越高，平均能量越大，常见应用有：

- LED 调光
- 电机调速
- 舵机控制

## 需要关注的两个量

- 频率：一秒钟重复多少次。
- 占空比：一个周期内高电平占多少比例。

## 配置思路

1. 选一个带 PWM 输出能力的定时器通道，例如 TIM3_CH1。
2. 把对应引脚配置成复用输出。
3. 设置预分频和 ARR，确定频率。
4. 改 CCR 寄存器或比较值，改变占空比。

## 一个简单示例

```c
HAL_TIM_PWM_Start(&htim3, TIM_CHANNEL_1);
__HAL_TIM_SET_COMPARE(&htim3, TIM_CHANNEL_1, 500);
```

如果 ARR 是 999，那么比较值 500 大致就是 50% 占空比。

## 用实验建立直觉

- 把 PWM 接到 LED：观察亮度变化。
- 把占空比从 10% 调到 90%：体会输出平均值的变化。
- 把频率调太低：你会看到 LED 明显闪烁。

## 常见问题

| 现象 | 可能原因 |
| --- | --- |
| 没有波形输出 | 引脚没有配置成复用功能 |
| 亮度不变 | 通道没启动或比较值没生效 |
| 电机抖动 | 频率过低、驱动能力不足或供电不稳 |

## 本节小结

PWM 其实就是“用时间比例去模拟不同强度”。理解这一点之后，很多执行器控制都会变得直观。
