# 第 3 节 · 给时间装上刻度：定时器

> 本节目标：理解 STM32 定时器的基本计数逻辑，并配置一个固定周期中断。

## 定时器能帮你做什么

定时器本质上是在“按某个频率计数”。当计到设定值时，就可以触发更新事件、中断、PWM 输出等功能。

## 最关键的两个参数

- 预分频器 Prescaler
- 自动重装值 Period / ARR

定时器溢出频率通常可以近似理解为：

计数频率 = 定时器时钟 / (PSC + 1)

更新频率 = 计数频率 / (ARR + 1)

## 一个 1ms 中断的典型配置思路

假设定时器时钟是 72MHz，可以先把预分频设到 7199，让计数频率变成 10kHz；再把 ARR 设成 9，就得到 1kHz 更新频率，也就是 1ms 一次中断。

## 常见回调函数

```c
void HAL_TIM_PeriodElapsedCallback(TIM_HandleTypeDef *htim)
{
  if (htim->Instance == TIM2)
  {
    tick_1ms++;
  }
}
```

## 定时器适合做哪些事

- 周期性任务调度
- 软件计时和超时判断
- 作为 PWM 的时间基准
- 编码器、输入捕获等更复杂外设功能的基础

## 初学者常见误区

- 只记结论，不会根据时钟反推参数。
- 不分清定时器时钟和系统时钟。
- 中断里做太多事，导致周期抖动。

## 建议练习

先让一个变量每 1ms 自增一次，再基于它实现一个“每 500ms 翻转 LED”的逻辑。这样你会发现，定时器比直接 `HAL_Delay()` 更适合做可控的时间管理。
