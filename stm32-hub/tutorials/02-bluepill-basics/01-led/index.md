# 第 1 节 · 嵌入式的 Hello World：点亮一只 LED

> 本节目标：完成你的第一个最小 STM32 程序，让板载 LED 按预期亮灭。

## 为什么点灯是入门第一关

点亮一只 LED，看起来简单，但它同时验证了四件事：

- 工程能正常创建。
- 时钟和初始化代码能正常生成。
- 编译下载链路是通的。
- 代码真的跑到了主循环。

## 基本配置思路

1. 在 CubeMX 中把 PC13 设置为 GPIO_Output。
2. 生成代码并打开工程。
3. 在主循环里周期性翻转引脚电平。

## 关键代码

```c
while (1)
{
  HAL_GPIO_TogglePin(GPIOC, GPIO_PIN_13);
  HAL_Delay(500);
}
```

如果你的板载 LED 是低电平点亮，那么翻转一次就会在亮和灭之间切换。

## 观察现象时要确认什么

- LED 是否真的在闪，而不是常亮或常灭。
- 闪烁周期是否接近 1 秒。
- 下载完成后复位，现象是否仍然存在。

## 常见问题

| 现象 | 可能原因 |
| --- | --- |
| LED 不亮 | 引脚配错、板子没供电、程序没下载进去 |
| LED 常亮 / 常灭 | PC13 低电平点亮，逻辑理解反了 |
| 下载成功但没效果 | 主循环被别的逻辑卡住，或者下载到错的芯片 |

## 试着再往前一步

把 `HAL_Delay(500)` 改成不同值，体会“代码参数变化 -> 物理现象变化”的直接关系。这种感觉后面学 PWM、串口、控制算法时都非常重要。
