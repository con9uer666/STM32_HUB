# 第 8 节 · 让外设彼此对话：I2C

> 本节目标：理解 I2C 的总线结构和主从关系，完成一次对常见器件寄存器的读写。

## I2C 的核心特点

I2C 只用两根线：

- SCL：时钟线
- SDA：数据线

多设备可以挂在同一条总线上，通过设备地址区分彼此。

## 入门时一定要知道的规则

- 总线通常需要上拉电阻。
- 同一条总线上地址不能冲突。
- 主机发起通信，决定什么时候读、什么时候写。

## 适合拿来练手的器件

- OLED 屏幕
- EEPROM
- MPU6050 等传感器

## 一个寄存器读取示例

```c
uint8_t who_am_i = 0;
HAL_I2C_Mem_Read(&hi2c1, dev_addr, reg_addr, I2C_MEMADD_SIZE_8BIT, &who_am_i, 1, 100);
```

## 调试 I2C 时的思路

1. 先确认硬件接线和上拉存在。
2. 再确认设备地址是否正确。
3. 然后检查读写方向和寄存器地址。
4. 最后再怀疑时序和频率。

## 常见问题

- 总线一直忙：某个设备拉住了线，或初始化异常。
- 返回超时：地址错、没上拉、器件没上电。
- 读到全 0 或全 255：寄存器地址、读写顺序或器件型号不对。

## 本节小结

I2C 非常适合连接低速配置类器件。你真正要掌握的，不只是 HAL API，而是“地址 + 寄存器 + 上拉 + 时序”这四个关键词。
