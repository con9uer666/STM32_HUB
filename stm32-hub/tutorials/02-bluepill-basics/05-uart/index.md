# 第 5 节 · 让芯片开口说话：串口

> 本节目标：完成一次最基础的串口收发，让 STM32 能把信息发到电脑，也能从电脑收回来。

## 为什么串口这么重要

串口是嵌入式调试和设备通信里最常见的入口之一。只要串口通了，你就拥有了一个非常高效的观察窗口。

## 最常见的接线

- STM32 TX -> USB 转串口 RX
- STM32 RX -> USB 转串口 TX
- GND -> GND

注意 TX 和 RX 要交叉接，地线必须共地。

## 常用参数

- 波特率：例如 115200
- 数据位：8
- 停止位：1
- 校验位：None

也就是常说的 115200 8N1。

## 发送一个字符串

```c
uint8_t msg[] = "Hello STM32\r\n";
HAL_UART_Transmit(&huart1, msg, sizeof(msg) - 1, 100);
```

## 接收数据时先别追求复杂

刚入门时，先用阻塞式或固定长度接收验证链路通不通。等你确认发送、接线和上位机都正常，再进入中断和 DMA。

## 常见问题

| 现象 | 排查方向 |
| --- | --- |
| 全是乱码 | 波特率不一致、时钟不准 |
| 一点反应都没有 | TX/RX 接反、没有共地、串口号选错 |
| 只能发不能收 | RX 引脚没配好，或者上位机没发送换行 |

## 建议你立刻做的两个实验

1. 上电后自动发送一行启动日志。
2. 每收到一个字节就原样回发，做最简单 echo。

做到这一步，你后面调试任何外设都会轻松很多。
